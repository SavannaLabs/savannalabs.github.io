Effective date: [EFFECTIVE DATE]

Interceptor is a Safari web extension for developers. It lets you define rules that mock or modify fetch and XMLHttpRequest responses in your own browser, so you can test how a web application behaves without changing its backend.

We do not collect any data

Interceptor does not collect, transmit, sell, or share any personal information.

There is no account, no sign-in, and no server operated by us. The extension makes no network requests of its own. It contains no analytics, no telemetry, no crash reporting, and no advertising or tracking of any kind.

What the extension stores, and where

Interceptor saves the interception rules you create — their names, URL patterns, HTTP methods, response bodies, headers, and transforms — along with the list of sites you have de-authorised.

This is stored using the browser's local extension storage (browser.storage.local) on your device only. It is never uploaded anywhere. Deleting the extension removes it.

If you use the Export or Share buttons, the resulting file goes wherever you choose to send it. That transfer is initiated by you and handled by macOS; the extension is not involved beyond producing the file.

What the extension can see

To do its job, Interceptor needs permission to run on the pages you visit. This lets it observe and alter network responses on any site, which is the entire function of the tool.

That access is used solely to match your rules against requests as they happen, in your browser, in memory. Response contents are not stored, logged, or transmitted. The extension has no way to send them anywhere, because it makes no network requests.

You can disable Interceptor for any individual site using the de-authorise button in the popup, or disable the extension entirely in Safari Settings.

Children

Interceptor is a developer tool and is not directed at children. It collects no data from anyone, of any age.
