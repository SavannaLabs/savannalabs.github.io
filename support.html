Support — Interceptor

Support contact: daniel.sm@me.com

Privacy policy: Privacy Policy

This page provides support information for Interceptor. It can be published (for example on GitHub Pages) and used as the "Support URL" in App Store Connect. Contact details and useful links are provided below.

How to get help

  1. Send an email to the support address above.
  2. (Optional) Open an issue on the project's public repository — if you choose to use Issues, include a permanent link to the issue here.
  3. When possible, attach an exported rules file (interceptor-rules.json) and a short set of steps to reproduce the problem.

Quick resolution steps (for end users)

  • Ensure the extension is enabled: Safari → Settings → Extensions → Interceptor.
  • Confirm the relevant rule is enabled in the Interceptor popup.
  • Reload the page and, if needed, toggle the extension off and on in Safari Settings.
  • Open Develop → Show JavaScript Console to view messages and any errors from the content/injected scripts.
  • If the issue relates to import/export of rules, export the rules and attach the resulting file to your report.

What to include in a bug report

Please include the following information — the more detail, the faster the diagnosis:

  • macOS version (e.g. macOS 13.5.2 — available from  → About This Mac).
  • Safari version (e.g. Safari 17.0).
  • Interceptor version and build number, if known.
  • Exact steps to reproduce the issue (as few steps as possible).
  • Example URL where the issue occurs (or note if it's a local endpoint like http://localhost:3000).
  • An exported rules file (interceptor-rules.json) when applicable.
  • Screenshots of the Interceptor popup and/or the JavaScript console with errors (or paste console text).

Example snippet you can run in the console to check whether the extension is intercepting fetch:

fetch('https://jsonplaceholder.typicode.com/posts')
  .then(r => r.text()).then(console.log).catch(console.error)

Instructions for sending attachments

  • Attach exported rule files and screenshots to the email or issue.
  • If sending console logs, prefer copying and pasting text rather than images to make searching easier.
