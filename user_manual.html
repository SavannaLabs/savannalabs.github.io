Interceptor — User Manual

Version: 1.0    Platform: Safari (macOS 12.3+)

Interceptor is a Safari Web Extension that intercepts and overrides fetch() and XMLHttpRequest (XHR) responses in real time. It lets you mock API responses, modify live data, and test edge cases without changing your backend.

Installation

  1. Open Xcode and build the Interceptor project.
  2. Open Safari and go to Safari > Settings > Extensions.
  3. Enable the Interceptor extension.
  4. The Interceptor icon appears in the Safari toolbar.

Quick Start

  1. Click the Interceptor icon in the Safari toolbar to open the popup.
  2. The example rule is pre-loaded — navigate to jsonplaceholder.typicode.com and make a fetch request.
  3. The response is intercepted and replaced with the mock data.
  4. Click + Add Rule to create your own rules.

The Popup

The popup is the main control panel. It contains a header, a site status bar, a toolbar, the rules list, and an Add Rule button. Use the toolbar to Export, Share, or Import rules.

Managing Rules

Creating a Rule

  1. Click + Add Rule.
  2. Fill in name, URL pattern, method, and action type.
  3. Complete the Mock Response or Modify Response section and click Save.

Editing & Enabling

Click the Edit button to change a rule. Use the toggle on each rule card to enable or disable it. Disabled rules are skipped.

Rule Editor

The editor opens in a separate window. Fields include Name, URL Pattern (use * as a wildcard), Method, and Action Type (Mock or Modify). Validation errors appear inline.

Mock Response

Mock returns a fabricated response without making any network request. You can set status code, body, headers, and delay.

Modify Response

Modify makes the original request but applies response transforms before the page receives it. Modify only works with fetch(). XHR requests fall through unless mocked.

Transforms

Transforms are applied sequentially. Types include Replace (regex), JSON Set (dot path), Prepend, and Append.

Export, Import & Share

Export produces interceptor-rules.json. Share opens the macOS share sheet. Import accepts either a bare array or an export envelope with a rules array.

Troubleshooting

Common issues: ensure the rule is enabled, site is not de-authorized, confirm the URL pattern and method, reload the page, or toggle the extension in Safari Settings.

Data Format Reference

{
  "id": "rule_1722268800000_a1b2",
  "name": "My Rule",
  "urlPattern": "*://api.example.com/*",
  "method": "GET",
  "enabled": true,
  "action": { "type": "mock", "statusCode": 200, "responseBody": "{\"key\": \"value\"}", "headers": {"Content-Type": "application/json"}, "delay": 0 }
}
